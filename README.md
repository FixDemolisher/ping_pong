# Управление
Левый игрок (Игрок 1) - W, S
Правый игрок (игрок 2) - ВВЕРХ, ВНИЗ

# Условия порожений
Левый игрок (Игрок 1) - Мяч улетел влево
Правый игрок (Игрок 2) - Мяч улетел вправо

# Возможные баги (фичи)
Если мяч залетел В РАКЕТКУ, то бует там дёргаться пока не выйдет

# Стратегия бесконечной игры
Игрок 1 всаёт в верхний левый край, Игрок 2 всиаёт в нижний правый край и не двигаться
